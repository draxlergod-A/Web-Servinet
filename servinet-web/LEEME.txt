SERVINET - PAGINA WEB ESTATICA

Tecnologias utilizadas:
- HTML5
- CSS3
- JavaScript puro (vanilla)

No utiliza Java, JavaFX, Spring Boot, frameworks ni base de datos.
No necesita instalacion ni servidor. Para verla, abre index.html en tu navegador.

CONTENIDO
- Presentacion principal de Servinet.
- Planes Básico y Premium de acuerdo con la imagen de referencia.
- Beneficios y disponibilidad de cobertura.
- Indicadores de ejemplo.
- Seccion de opiniones de muestra.
- Preguntas frecuentes desplegables.
- Diseño adaptable a computadoras, tabletas y celulares.

IMPORTANTE ANTES DE PUBLICAR
1. Los precios y velocidades se tomaron de la imagen de referencia: Básico 50 Mbps a S/ 49.90 y Premium 200 Mbps a S/ 89.90, ambos con instalación incluida.
2. Las cifras de clientes, atenciones, zonas y satisfacción son datos ficticios de demostración. Reemplazarlos por cifras reales o eliminarlos.
3. Las reseñas y nombres son ejemplos de diseño. Reemplazarlos por opiniones reales y autorizadas.
4. Agregar el número oficial de WhatsApp o los datos de contacto de Servinet en la sección de cobertura.

La web es solamente informativa. No registra solicitudes, no guarda datos ni se conecta a una base de datos.
